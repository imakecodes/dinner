# Agent Rules

> [!IMPORTANT]
> **Always read and follow the instructions in @AGENTS.md in addition to these rules.**

## Code Quality & Testing
- **Test Coverage**: Maintain a minimum of **85% code coverage** for the project.
- **Unit Tests**: All new components and services must be accompanied by unit tests.
- **Testing Stack**: Use Jest and React Testing Library.

## Coding Standards
- **UI/UX**: Prioritize "Wow" factor and premium aesthetics with PoE2 gaming theme.
- **Strict Typing**: No `any` types unless absolutely necessary.
- **Structure**: Follow the existing feature-based folder structure.

## PoE2 Domain Consistency
- **Terminology**: Always use PoE2 gaming terminology (Hideout, Build, Stash, Checklist, Party Member)
- **Domain Validation**: Ensure all AI-generated content is strictly within Path of Exile 2 domain
- **Fact Verification**: Validate all PoE2 mechanics claims against official sources
- **Knowledge System**: Leverage the PoE2 knowledge resolver for entity verification
